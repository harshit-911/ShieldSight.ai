02. TRI-MODAL AI ARCHITECTURE

3 Multimodal AI Safety Engines

ShieldSight AI combines three AI techniques to protect against all forms of harmful media.

1. Computer Vision (ONNX)
Dual ONNX neural models (opennsfw2.onnx & violence.onnx) classifying explicit imagery and graphic violent scenes in ~26ms.
2. Multilingual NLP Filter
Natural Language Processing engine supporting English, Romanized Hinglish, and Devanagari Hindi (हिंदी).
3. WASM OCR Engine
Tesseract.js compiled to WebAssembly extracting text embedded inside images (memes, text banners) and feeding it into the NLP engine.
03. SYSTEM EXECUTION PIPELINE

4-Step Real-Time Protection Flow

Decoupled execution pipeline bypassing Service Worker limits via Chrome Offscreen Documents.

STEP 01
DOM Scanning
MutationObserver automatically discovers text nodes, subframes, and images as you scroll any webpage.
STEP 02
Offscreen AI Route
Sends image buffers and text streams into Chrome's Offscreen Document context via Extension Messaging.
STEP 03
WebGL GPU Execution
Executes ONNX Runtime WebGL GPU tensor operations and WebAssembly OCR threads in under 30ms.
STEP 04
Dynamic Redaction
Applies CSS backdrop-filter blur and attaches an interactive 🛡️ "Sensitive Language Hidden" safety badge.
