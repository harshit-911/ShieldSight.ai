01. THE PROBLEM WE SOLVED

Why On-Device AI is Better

Traditional parental control software sends private user data to cloud APIs, causing privacy concerns and slow page loads.

❌ Traditional Cloud Filters
  • • Sends private photos, chat logs & history to third-party servers.
  • • Slow network latency (300ms–1000ms delay per webpage request).
  • • High cloud infrastructure and API subscription costs.
✅ ShieldSight AI (On-Device)
  • • 100% local processing inside browser memory. Zero privacy leaks.
  • • Blazing fast sub-30ms AI classification using GPU acceleration.
  • • Completely free to operate with zero server infrastructure overhead.
02. MULTIMODAL AI ENGINES

3 AI Safety Engines in One

ShieldSight AI combines three AI techniques to protect against all forms of harmful media.

👁️
1. Vision Engine
Runs computer vision neural models (ONNX WebGL) to detect explicit/adult images and graphic violence.
💬
2. Language Engine
NLP text filter supporting English, Hinglish, and Devanagari Hindi (हिंदी) toxicity detection.
🔤
3. WASM OCR Engine
Extracts text hidden inside images (memes, text banners) and checks it for toxic content.

05. MULTILINGUAL SAFETY

English, Hinglish & Hindi Protection

Understands regional language inflections, slang, and Devanagari script.

🇮🇳 Supported Languages & Scripts
  • • English: Standard cyberbullying & harassment filter.
  • • Romanized Hinglish: Catching Indian slang (e.g., chutiya, bhosdike, gandu).
  • • Devanagari Hindi (हिंदी): Native script moderation (e.g., चूतिया, मादरचोद, गधा).
  • • Leetspeak Obfuscation: Handles masked words like chut!ya, b*osdike.
🎯 Why This Matters
Most commercial extension filters only work for plain English. ShieldSight AI is specifically designed to protect multi-lingual users across India and global communities who use Hinglish and regional scripts on social media and chat apps.
