01. PROBLEM STATEMENT & MOTIVATION

The Privacy & Latency Crisis in Web Safety

Existing parental control tools compromise personal privacy and degrade browser performance.

⚠️ Cloud API Flaws (Traditional Tools)
  • Privacy Intrusion: Transmits private browsing history, chat logs, and photos to third-party servers.
  • High Network Latency: 300ms–1000ms per network API call causes noticeable page load lag.
  • Recurring API Costs: High operational expenses per thousand API inspection requests.
  • Static Domain Lists: Easily bypassed on dynamic Single Page Applications (SPAs).
🛡️ ShieldSight AI Solution
  • 100% On-Device AI: Zero user data, photos, or chat logs ever leave the local machine.
  • Sub-30ms Inference: Executes directly in browser GPU memory via WebGL acceleration.
  • Zero Server Infrastructure Costs: All neural weights bundled directly in the extension package.
  • Dynamic DOM Mutation Observer: Monitors dynamic SPA updates in real-time.

03. SYSTEM ARCHITECTURE

Chrome Manifest V3 Execution Pipeline

Decoupled multi-tier architecture utilizing Offscreen Documents to bypass Service Worker limits.

1
DOM Discovery Engine (Content Script)
MutationObserver scans incoming text nodes, subframes, and images across all webpage domains.
2
Chrome Extension Messaging Bridge
Routes image buffers and text streams into Chrome's background Offscreen Document context.
3
Offscreen Machine Learning Context
Executes ONNX Runtime WebGL GPU tensor operations and WebAssembly OCR threads without freezing user UI tabs.
4
Dynamic Blur & Safety Redaction
Applies CSS backdrop-filter blur and attaches non-intrusive interactive safety badges with session "Reveal" options.
