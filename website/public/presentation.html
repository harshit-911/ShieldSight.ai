1. MOTIVATION FOR WORK

The Need for On-Device Content Moderation

Addressing critical privacy risks, cloud latency bottlenecks, and digital safety needs for modern web users.

🔒 Data Privacy Crisis
Traditional content moderation software sends private user browsing history, chat logs, and photos to third-party cloud API servers, exposing families to severe data privacy breaches.
⚡ High Latency Overhead
Cloud API calls introduce 300ms–1000ms network delay per image/text inspection, freezing page rendering and degrading user browsing experience.
💡 On-Device AI Solution
ShieldSight AI processes neural networks 100% locally on the user's GPU/CPU in under 30ms, eliminating cloud API costs and guaranteeing absolute privacy.

3. METHODOLOGY & TECHNIQUES

Tri-Modal Methodology & AI Techniques

Explaining the methods and technical components used to perform multimodal content moderation.

1. Computer Vision (ONNX)
Executes dual neural models (opennsfw2.onnx & violence.onnx) on Float32Array BGR tensors ($224 \times 224 \times 3$) using WebGL shader acceleration.
2. Multilingual NLP Engine
Custom preprocessing engine (TextNormalizationEngine.ts) handling leetspeak, Hinglish slang, and Devanagari Hindi (हिंदी) across 6 harm categories.
3. WASM OCR Bridge
Integrates Tesseract.js compiled to WebAssembly inside Chrome Offscreen Document to extract text embedded inside images (memes, text banners).
